# 🎮 Pixel Arena

O **Pixel Arena** é uma página de jogos feita com HTML, CSS e JavaScript puro.

Ele possui jogos **multiplayer local**, onde dois jogadores jogam no mesmo dispositivo, ou jogam contra a máquina dependendo do jogo.

---

## 🎮 Jogos

### 🧠 Genius
- Jogo de memória de cores onde o jogador precisa repetir a sequência mostrada pelo sistema.
- Multiplayer local (Jogador 1 e Jogador 2)
---

### ✊ Pedra, Papel e Tesoura
Jogo contra a máquina com sistema de campeonato.

- Multiplayer local (Jogador 1 e Jogador 2)
- Modos: Melhor de 3, Melhor de 7 e Modo Livre (contra a máquina)

---

### ❓ Jogo de Adivinhação
- O jogador tenta acertar um número secreto com dicas de maior ou menor. 
- Multiplayer local (Jogador 1 e Jogador 2)

---

### ⭕ Jogo da Velha
Jogo clássico de X e O com dois jogadores.

- Multiplayer local
- Alternância automática de turnos

---

## 📦 Estrutura dos arquivos

Cada jogo possui seus próprios arquivos:

- HTML do jogo
- CSS do jogo
- JavaScript do jogo
