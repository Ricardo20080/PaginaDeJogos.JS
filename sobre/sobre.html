Projeto Acadêmico

Frontend Inteligente com JavaScript

A PIXEL ARENA é uma plataforma web de jogos interativos desenvolvida como trabalho acadêmico da disciplina Programação Website I.


O principal objetivo do projeto foi aplicar, de forma prática, conceitos fundamentais do desenvolvimento frontend, utilizando HTML, CSS e JavaScript.


Durante o desenvolvimento, foram trabalhados:


  • Estruturação semântica com HTML
  • Estilização responsiva com CSS
  • Manipulação dinâmica do DOM
  • Eventos de clique e interatividade
  • Arrays, funções e condicionais
  • Persistência de dados com localStorage
  • Organização modular de arquivos

A plataforma reúne quatro jogos: Genius, jogo da velha, jogo da adivinhaçao e pedra papel e tesoura.


Mais do que desenvolver jogos, este projeto representa a união entre programação, design, lógica computacional e experiência do usuário.
